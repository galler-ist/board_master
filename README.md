# Board Master - 프로젝트 계획서

## 개요

이 문서는 현대적인 보드게임 리뷰 웹사이트인 Board Master 프로젝트의 기능, 디자인 및 개발 계획을 설명합니다.

## 현재 상태

이 프로젝트는 React Router를 사용한 다중 페이지 아키텍처를 활용하며, 다국어 지원(i18n) 및 다크/라이트 테마 전환 기능을 제공합니다. Cloudflare Pages를 통한 자동 배포가 설정되어 있으며, Google AdSense 스크립트가 통합되어 있습니다. AdSense 검토 준비를 위한 콘텐츠가 풍부하게 포함되어 있습니다.

## 개발 계획

### 1-8단계 (완료)

*   홈페이지, 다국어 지원, 테마 전환, 문의 양식, 다중 페이지 아키텍처, 리뷰 상세 페이지, Google AdSense 스크립트 통합 및 AdSense 검토 준비 콘텐츠가 구현되었습니다.

### 9단계: AdSense 규정 준수 - ads.txt 및 CMP 지침

**목표:** 공인 디지털 판매자(`ads.txt`) 및 사용자 동의(CMP)에 대한 Google AdSense 규정 준수 요구 사항을 해결합니다.

**주요 기능:**

*   **`ads.txt` 파일 생성:** 사용자 게시자 ID로 `ads.txt` 파일을 생성하고 웹사이트의 루트 디렉터리에 배치합니다.
*   **동의 관리 플랫폼(CMP) 지침:** Google 인증 CMP를 선택하고 통합하는 방법에 대한 명확한 지침을 제공합니다(직접 구현은 AI의 능력 밖이므로).

**구현 세부 정보:**

*   **파일 생성:** 프로젝트 루트에 `ads.txt`.
*   **지침:** CMP 통합에 대한 텍스트 기반 지침이 사용자에게 제공됩니다.
*   **커밋 메시지:** `feat: AdSense compliance - add ads.txt & CMP guidance`.
